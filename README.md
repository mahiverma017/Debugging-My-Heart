# 💖 Debugging My Heart – An Interactive Love Story

> A playful Valentine-themed interactive web experience where **love meets code**. 💻❤️

**Debugging My Heart** is a creative interactive website built using **HTML, CSS, and Vanilla JavaScript**. It combines storytelling, animations, and DOM manipulation to create an engaging and fun digital love story.

## 🌐 Live Demo

✨ **[View Live Project](https://mahiverma017.github.io/Debugging-My-Heart/)**

## ✨ Features

* ⌨️ Typewriter text animation
* 💬 Interactive dialogue progression
* 🃏 Clickable story cards
* 💓 Heartbeat-triggered transition
* 💌 Interactive proposal screen
* 💕 Floating heart animations
* 💥 Double-click heart burst effect
* 🔄 Restart functionality
* 🎨 Responsive and playful UI

## 🛠️ Tech Stack

* **HTML5** – Page structure
* **CSS3** – Styling, animations & transitions
* **JavaScript** – Interactions and DOM manipulation
* **Font Awesome** – Icons
* **Google Fonts** – Typography

## 🚀 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/mahiverma017/Debugging-My-Heart.git
```

### 2. Navigate to the project

```bash
cd Debugging-My-Heart
```

### 3. Run the project

Open `index.html` directly in your browser.
